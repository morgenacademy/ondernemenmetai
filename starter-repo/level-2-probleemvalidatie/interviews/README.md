# Interviews

Eén bestand per interview: `01-rol-plaats.md`, `02-rol-plaats.md`, enzovoort. Gebruik een rol en een plaats, nooit een naam.

Je opname mag hier staan, naast het bestand. Git slaat opnames over (zie `.gitignore`): ze blijven op je eigen computer. Alleen het uitgeschreven `.md`-bestand gaat naar GitHub.
