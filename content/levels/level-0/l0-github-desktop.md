Met GitHub Desktop zet je je repo op je computer en zet je je wijzigingen weer online. Je hoeft er niets voor te typen.

1. Download GitHub Desktop via [github.com/apps/desktop](https://github.com/apps/desktop).
<!-- alleen:mac -->
2. Open het gedownloade bestand en sleep **GitHub Desktop** naar je map **Programma's**.
<!-- /alleen -->
<!-- alleen:windows -->
2. Open het installatiebestand. GitHub Desktop installeert zichzelf en opent daarna vanzelf.
<!-- /alleen -->
3. Kies **Sign in to GitHub.com** en log in met je GitHub-account.

<!-- alleen:windows+claude-code -->
Vraagt de Claude-app om Git? Installeer dan [Git for Windows](https://git-scm.com/download/win).
<!-- /alleen -->
