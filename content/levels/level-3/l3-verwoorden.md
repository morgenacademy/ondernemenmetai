Je madlib en je canvas gingen nog over je eerste idee. Nu krijgen ze een versie voor je gekozen oplossing.

1. Geef je AI de opdracht hieronder. Je AI schrijft `waardepropositie.md`: de langere tekst bij je oplossing. Je AI vindt ongeveer de helft van de antwoorden al in je repo en vraagt alleen naar de rest.
2. Je AI stelt op een branch een nieuwe madlib en een nieuwe aanbodkant van je canvas voor. Dat zijn jouw keuzes, dus het gaat via een pull request.
3. Klik in GitHub Desktop op **Publish branch** en **Create Pull Request**, en op GitHub op **Merge pull request** als het klopt.

Je AI gebruikt hier skill `waardepropositie-bouwer`: hij stelt je de vragen die nog openstaan en zet je oplossing in één krachtige tekst. Je vindt de skill in je repo, in `skills/waardepropositie-bouwer/SKILL.md`.
