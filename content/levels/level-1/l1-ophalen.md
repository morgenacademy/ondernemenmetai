Aan het begin van deze stap zei je AI iets als: "Ik heb idee.md, visie.md, madlib.md en aannames.md opgehaald." Dat zijn de bestanden die je hier invulde.

### Wat je hier invult, komt op GitHub

Ondernemen met AI zet je formulieren direct in je repo op GitHub. Je AI werkt op je computer. Daarom haalt je AI aan het begin van elke sessie eerst de nieuwste versie op. Dat heet ophalen, of pull. Je hoeft er zelf niets voor te doen.

### Wat je AI maakt, zet jij op GitHub

Andersom gaat het met push. Je canvas en je feedback maakt je AI op je computer. Ondernemen met AI ziet ze pas als ze op GitHub staan: klik in GitHub Desktop op **Push origin**, of vraag je AI om te pushen.

### Je hoeft dit niet te onthouden

De vraag onder het plaatje werkt altijd. Je AI antwoordt in één zin: wat nog alleen op je computer staat, en wat nog op GitHub klaarstaat.
