Aan het begin van deze stap zei je AI iets als: "Ik heb idee.md, visie.md, madlib.md en aannames.md opgehaald." Dat zijn de bestanden die je hier op het platform invulde.

### Wat je op het platform invult, komt op GitHub

Het platform zet je formulieren direct in je repo op GitHub. Je AI werkt op je computer. Daarom haalt je AI aan het begin van elke sessie eerst de nieuwste versie op. Dat heet ophalen, of pull. Je hoeft er zelf niets voor te doen.

### Wat je AI maakt, zet jij op GitHub

Andersom gaat het met push. Je canvas en je feedback maakt je AI op je computer. Het platform ziet ze pas als jij in GitHub Desktop op **Push origin** klikt.

### Je hoeft dit niet te onthouden

Vraag je AI: "Is alles in sync?" Je AI antwoordt in één zin: wat nog alleen op je computer staat, en wat nog op GitHub klaarstaat.
